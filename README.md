# MentalMarket

**基于心智理论（Theory of Mind）认知层级的大语言模型金融市场仿真系统**

MentalMarket 构建了一个由上千个 LLM Agent 组成的虚拟金融市场，通过连续双向拍卖（CDA）机制进行多标的交易博弈。每个 Agent 被赋予不同阶次的心智理论（ToM）能力——从零阶散户的直觉交易，到二阶策略者的"他认为我认为"深度博弈推理——以研究认知层级差异如何驱动价格发现、行为偏差涌现和财富分配演化。

---

## 核心设计

### 认知层级体系（ToM Hierarchy）

| 阶次 | 认知特征 | 典型行为 |
|------|----------|----------|
| **ToM 0** | 零阶心智，凭直觉和市场信号交易 | 跟随趋势、追涨杀跌 |
| **ToM 1** | 一阶心智，思考"其他交易者会怎么做" | 逆向思维、博弈定价 |
| **ToM 2** | 二阶心智，推理"别人认为其他人会怎么做" | 深度策略、欺骗操纵 |

Agent 的认知能力完全由 System Prompt 定义——仅设定认知框架，不指定具体策略或偏差。行为金融偏差（处置效应、羊群效应、过度自信等）从认知约束中**自然涌现**，而非由指令显式触发。

### 多标的交易市场

- **10 只行业指数**：基于上证 A 股真实行业分类（化工制药、金融服务、科技通信、房地产等），以历史行情数据作为基准
- **连续双向拍卖**：完整的限价订单簿实现，支持价格优先-时间优先撮合、涨跌停限制（±10%）、最小变动价位、手续费
- **初始持仓分配**：基于情绪值 × 市值权重的复合概率模型，每个 Agent 持有 1–6 只指数的异质化组合
- **资金分布**：支持幂律分布（模拟真实市场的财富不等式）或等额分布，可按 ToM 层级差异化

### 事件驱动仿真引擎

采用离散事件驱动架构，以最小堆实现全局事件队列：

- **Agent 唤醒**：泊松过程建模交易到达，按 ToM 层级差异化到达率
- **延迟模型**：感知 → 决策 → 提交 → 报告四阶段延迟，高阶 Agent 反应更快
- **新闻冲击**：外生事件注入，支持随机抽样和按日全量标题两种模式
- **批量并发**：同一时间窗口内的 Agent 决策请求被批量派发至 LLM，最大化推理吞吐

### LLM 推理架构

每个 Agent 的每次决策都是一次完整的 LLM 调用：

- **Prompt 结构**：System（身份 + 认知框架）→ User（行情 + 新闻 + 社交流 + 持仓），共享市场前缀最大化 API 前缀缓存命中
- **工具调用（Tool Use）**：Agent 通过 LangGraph 工具链完成复合操作——设定交易计划、发布社交帖子、撤销挂单、制定跨天欺骗策略（仅 ToM 2），最后提交交易决策
- **多服务商负载均衡**：按 ToM 层级路由到不同 LLM 提供商（DeepSeek、Qwen、Moonshot 等），支持并发限制和自动故障转移

### 社交网络与信息传播

- **有向关注图谱**：Agent 间建立关注关系，信息沿社交网络定向传播
- **KOL 机制**：粉丝数达到阈值的 Agent 自动获得 KOL 身份，其帖子在信息流排序中获得更高权重
- **影响力动态**：点赞、踩、转发改变影响力分数，每日衰减防止永久累积
- **声誉系统**：延迟评估帖子中市场预测的准确性，滑动窗口追踪声誉分数

### 行为偏差涌现检测

系统实时计算 9 类行为金融指标，观测认知约束下的偏差涌现：

| 偏差类型 | 检测方法 |
|----------|----------|
| 处置效应 | Odean (1998) PGR/PLR 方法 |
| 过度自信 | 换手率与持仓集中度 |
| 羊群效应 | 顺势/逆势交易比率 |
| 彩票偏好 | 赌博式抄底行为检测 |
| 损失厌恶 | 未实现盈亏方向分析 |
| 投资组合多样性不足 | 持仓 HHI 集中度 |
| 自我实现泡沫 | 信心-价格协同偏离 |
| 群体极化 | 情绪分裂与信息茧房 |
| 信息级联 | 连续同向交易判定 |

### 动态演化

可选启用 ToM 层级演化：连续亏损的低阶 Agent 自动升级认知层级，观测市场在认知竞争压力下的均衡演化路径。

## 评估体系

`evaluation/` 目录提供一套完整的定量评估工具：

- **拟合准确性**：模拟价格与真实行情的 Pearson 相关系数、方向一致性、RMSE
- **Kyle's Lambda**：市场流动性与信息不对称度量
- **尾部指数（Tail Index）**：收益率分布的厚尾特征分析
- **波动率聚类**：GARCH 效应与持续性检测
- **财富不平等**：Gini 系数与按 ToM 层级的财富分布
- **价格发现效率**：信息纳入速度与效率指标
- **市场微观结构**：买卖价差、订单簿深度、成交量分析

## 实时可视化看板

内置 WebSocket 实时推送的 Vue 3 前端看板，包含：

- **指数总览**：10 只指数的实时价格、涨跌幅、迷你走势图（支持真实曲线对比）
- **大盘走势**：等权综合指数的实时价格与成交量双轴图
- **订单簿深度**：L2 盘口的实时买卖挂单分布
- **情绪面板**：全市场情绪指标与趋势
- **技术指标**：SMA、RSI、动量等经典技术分析
- **Agent 排行**：财富、收益率、交易频率的实时排名
- **ToM 分析**：按认知层级的财富分布、决策分布、心智推理可视化
- **行为偏差曲线**：各类偏差指标的实时演化曲线
- **社交网络**：D3.js 力导向图可视化关注关系与 KOL 分布
- **信息级联与极化**：群体行为的实时监测

## 设计特色

1. **涌现而非预设**：行为偏差不是编码在规则里的，而是从 LLM 的认知约束中自然涌现，更接近真实的认知科学机制
2. **完整的市场微观结构**：不是简化的"买/卖/持有"模拟，而是带限价订单簿、涨跌停、手续费、订单 TTL 的完整连续双向拍卖
3. **异质性 Agent 群体**：资金幂律分布 + 认知层级分层 + 持仓异质化 + 社交网络差异化，避免"代表性 Agent"假设
4. **社交信息生态**：Agent 不仅交易，还在社交网络上发帖、互动、形成 KOL、建立声誉，信息传播影响交易决策
5. **多层级博弈**：ToM 认知层级形成自然的博弈深度梯度——零阶看市场，一阶看人，二阶看"人看人"，且二阶可制定欺骗策略
6. **可复现与可配置**：全部参数集中在 YAML 文件中，支持随机种子固定、断点续跑、checkpoint 恢复
7. **实时观测**：内置 WebSocket 看板，仿真运行中即可实时观察价格、行为偏差、社交网络等所有维度的演化
