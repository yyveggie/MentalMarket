# 损失厌恶排序图说明

---

## 一、这张图在讲什么

一句话：**心智阶数越高（ToM0 → ToM1 → ToM2），Agent 的损失厌恶程度越低**。

具体数值：

| 心智层级 | 损失厌恶代理指标 λ̂ | 含义 |
|---------|---------------------|------|
| **ToM 0** | **2.34** | 最损失厌恶（扛亏最严重） |
| **ToM 1** | **1.62** | 中等损失厌恶 |
| **ToM 2** | **1.06** | 接近风险中性（理性止损） |

---

## 二、什么是"损失厌恶"

### 2.1 概念（来自行为金融学）

人在面对同等金额的盈利和亏损时，**亏损带来的痛苦通常大于盈利带来的快乐**。这种不对称叫**损失厌恶（Loss Aversion）**。

经典例子：
- 捡到 100 元：开心程度 = +1 单位
- 丢了 100 元：痛苦程度 = -2.25 单位（约为开心程度的 2.25 倍）

这个 "2.25" 就是著名的 **Kahneman-Tversky λ 系数**（前景理论，1979/1992）。

### 2.2 损失厌恶在交易中怎么表现

损失厌恶的交易员往往：

- **扛亏不卖**：亏了不愿认，心想"再等等就回来了"，结果亏得更深才被迫卖
- **急于止盈**：赚了一点就赶紧卖，怕到手的利润跑了
- **结果**：每次已实现亏损的幅度，比每次已实现盈利的幅度大得多

反之，不损失厌恶（理性）的交易员：

- **及时止损**：亏了一点就断臂离场，每次亏损幅度小
- **让盈利奔跑**：赚了继续拿，每次盈利幅度大

---

## 三、图里的 λ̂ 怎么算出来的

### 3.1 公式

$$
\hat{\lambda} = \frac{\text{平均每次已实现亏损的幅度}}{\text{平均每次已实现盈利的幅度}}
$$

简写：

```
λ̂ = avg(|亏损%|) / avg(|盈利%|)
```

- "已实现" = Agent 确实把股票卖掉了（从浮动变确定）
- "幅度" = 卖价相对买价的百分比偏离（`|卖价 - 买价| / 买价`）

### 3.2 具体例子

假设某 Agent 在仿真里共卖出 10 次：

- 其中 6 次是盈利卖出，平均赚 3%
- 其中 4 次是亏损卖出，平均亏 9%

那么：

```
λ̂ = 9% / 3% = 3.0
```

这个 Agent 的 λ̂ = 3.0，表明他**平均扛亏的幅度是止盈幅度的 3 倍** → 明显损失厌恶。

### 3.3 判读标准

| λ̂ 范围 | 解读 |
|--------|------|
| λ̂ > 1 | **损失厌恶**（扛亏 > 止盈）|
| λ̂ = 1 | 风险中性（扛亏 ≈ 止盈）|
| λ̂ < 1 | 风险寻求 / 反向（止盈 > 扛亏，少见）|

图里的**虚线**就是 λ̂ = 1 这条分界线。

## 四、重要：λ̂ ≠ Kahneman-Tversky 的真 λ

### 为什么特别强调这点

前景理论里的 λ ≈ 2.25 是**效用函数的参数**，必须通过**标准化的概率选择实验**测出来（让实验对象在"50% 赢 100，50% 亏 X" 和 "0 元" 之间选择，反推 λ）。

我们这里的 λ̂ 是**观察到的交易行为的比值**，是**行为代理指标**，不是真 λ。

### 两者关系

- **方向一致**：λ̂ > 1 的人确实更损失厌恶
- **数值不等**：λ̂ = 2.34 ≠ "λ = 2.34"。两者的尺度、分布、物理含义都不同
- **更准确的叫法**：
  - "已实现亏损-收益幅度比"
  - "损失厌恶代理指标"
  - "行为层面的损失厌恶估计"

### 汇报 / 写作时的严谨说法

> "我们使用已实现亏损与收益幅度之比（λ̂）作为损失厌恶的**行为代理指标**。这并非经典前景理论中的 λ 参数，但在方向上一致：λ̂ > 1 反映损失厌恶倾向。"

这样既讲清楚了故事，又避免被追问"怎么和文献里 2.25 对不上"。

## 五、怎么读图里的每一个元素

### 5.1 三根柱子

- **蓝柱（ToM 0）**：λ̂ = 2.34
- **橙柱（ToM 1）**：λ̂ = 1.62
- **红柱（ToM 2）**：λ̂ = 1.06

柱子高度 = 所有实验池化后的**加权平均** λ̂。

### 5.2 误差条（柱子顶部的小 T 字）

表示 **95% bootstrap 置信区间**，大致可以理解为"真实均值有 95% 的概率落在这个区间里"。

| ToM | 95% CI |
|-----|--------|
| ToM 0 | [2.23, 2.45] |
| ToM 1 | [1.52, 1.72] |
| ToM 2 | [0.96, 1.17] |

**三个区间互不重叠** → 差异是统计显著的，不是偶然。

### 5.3 λ̂ = 1 虚线

损失厌恶 vs 风险中性的分界线：

- **ToM 0 远高于 1**：明显损失厌恶
- **ToM 1 明显高于 1**：仍然损失厌恶但缓解
- **ToM 2 紧贴 1**：已经非常接近风险中性

## 六、结论可以怎么讲

### 短版（一两句话）

> 随着 Agent 心智推理阶数的提高，损失厌恶程度单调下降。ToM 2 的 λ̂ 已经接近 1（风险中性分界线），说明**二阶心智推理能力显著缓解了损失厌恶偏差**。

### 长版（一段话）

> 我们使用已实现亏损-收益幅度比 λ̂ 作为损失厌恶的行为代理指标。池化所有实验数据后，三种心智层级的 λ̂ 呈现清晰的单调递减：ToM 0 为 2.34，ToM 1 降至 1.62，ToM 2 进一步降至 1.06。三组 95% 置信区间互不重叠，差异统计显著。特别值得注意的是，ToM 2 的 λ̂ 已逼近风险中性分界线（λ̂ = 1），表明具备二阶心智推理能力的 Agent 在交易中能更有效地执行"截断亏损、放任盈利"的理性止损策略，显著摆脱了低阶 Agent 扛亏不卖的心理倾向。

## 七、为什么 ToM 阶数越高损失厌恶越低（机制解释）

可以讲的几条因果假说：

1. **信息处理能力**
   - ToM 0 没有对他人信念的建模，亏损时只能依赖朴素的"再等等"策略 → 扛到底
   - ToM 2 能建模"别人如何看待这只票"，甚至"别人如何看待别人的预期"，可以识别下跌是短期噪音还是趋势反转 → 及时出清

2. **止损纪律**
   - 高阶推理让 Agent 能**预判自己扛下去会更亏**，从而愿意先认赔
   - 低阶 Agent 缺乏这种前瞻，只能被市场拖到更深再被迫止损

3. **反向利用羊群**
   - ToM 2 可以观察到散户（低阶）正在集体扛亏 → 借此反向操作
   - 在噪音交易者的损失厌恶行为上"收割"，自身保持理性

## 八、局限 / 需要诚实说明的点

| 局限 | 如何回应 |
|------|---------|
| λ̂ ≠ 真 λ | 第四节已说明：用"行为代理指标"这个说法 |
| 部分实验样本量小（如 6:3:1 里 ToM 2 只有 10 个 agent）| 主图已池化所有实验，总样本 n=315+，稳健 |
| 本指标受交易频率影响 | 已通过"每 Agent 末期 λ̂"的取值口径降低了这个偏差 |
| 因果 vs 相关 | 仿真中 ToM 阶数是**唯一变量**，其他条件对齐，因此这里的单调关系是因果性的 |

## 九、数据来源与复现

- **原始数据**：`runs/<实验名>/behavioral_biases.jsonl` 中的 `lambda_estimate` 字段
- **聚合口径**："每 Agent 末期 λ̂" — 每个 Agent 取其仿真结束时的最终 λ̂ 估计，跨实验合并后按 ToM 平均
- **样本总数**：ToM 0 = 339 / ToM 1 = 346 / ToM 2 = 315
- **统计方法**：2000 次 bootstrap 重采样估计 95% 置信区间
