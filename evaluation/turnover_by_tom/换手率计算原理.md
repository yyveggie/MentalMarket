# 平均日换手率（Daily Turnover Rate）计算原理

## 1. 换手率的定义

换手率（Turnover Rate）衡量**单位时间内交易额相对于持有资产总值的比例**，是行为金融中检测**过度自信偏差（overconfidence bias）**的核心指标（Odean, 1999; Barber & Odean, 2000）。

在 MentalMarket 仿真系统中，每个 Agent 的单日换手率定义为：

$$
\text{turnover\_rate} = \frac{\text{daily\_trade\_notional}}{\text{total\_asset}}
$$

- **`daily_trade_notional`**：该 Agent 当日所有成交的名义金额总和（买 + 卖，按成交价 × 成交量累加）
- **`total\_asset`**：该 Agent 当前的总资产（现金 + 持仓市值）

数值语义：
- `0.10` 表示当日交易额等于总资产的 10%
- `1.00` 表示当日完整换了一次仓

## 2. 字段产生机制（代码层）

### 2.1 日内累积

每发生一笔成交，`daily_trade_notional` 累加（`@/Users/mushroom/Desktop/MentalMarket/app/domain/behavioral_bias.py` 相关逻辑）：

```python
turnover_rate = round(daily_trade_notional / total_asset, 6) if total_asset > 0 else 0.0
```

该值被写入 `behavioral_biases.jsonl` 中每一条成交记录。

### 2.2 跨日重置

每个交易日开始时，计数器被重置（`@/Users/mushroom/Desktop/MentalMarket/app/domain/agent_analytics.py:490-497`）：

```python
@staticmethod
def _maybe_reset_daily_counters(agent, trading_day):
    if trading_day > agent.last_turnover_reset_day:
        agent.daily_trade_notional = 0.0
        agent.daily_trade_count = 0
        agent.daily_trade_symbols = []
        agent.last_turnover_reset_day = trading_day
```

**关键推论**：在同一个交易日内，`turnover_rate` 单调递增；该日最后一笔成交的 `turnover_rate` 即为**当日终盘换手率**（= 当日完整的日换手率）。

## 3. 数据源文件

`runs/<实验>/behavioral_biases.jsonl`

每行一条 JSON 记录，对应一次成交事件的行为偏差快照。相关字段：

| 字段 | 含义 |
|------|------|
| `agent_id` | 成交 Agent 的 ID |
| `trading_day` | 该笔成交所在的交易日（从 1 开始） |
| `tom_level` | Agent 的心智层级（0 / 1 / 2） |
| `turnover_rate` | 当前累积换手率（日内递增，跨日重置） |
| `daily_trade_notional` | 当日累积成交额（内部字段） |
| `daily_trade_count` | 当日累积成交笔数 |
| `overconfidence_flag` | 换手率是否超过阈值，标记过度自信 |

每个实验 ~10 万条记录（1000 Agent × 100 交易日 × 多笔成交）。

## 4. 聚合算法

### 4.1 单个实验的聚合流程

```python
# Step 1: 为每个 (agent, day) 取当日终盘换手率
daily_max[(aid, day)] = max(所有该 (aid,day) 的 turnover_rate)
```

**为什么取 max**？因为日内 `turnover_rate` 单调递增，同一天的最大值即为**当日末笔成交之后的累积换手率** ≈ 该 Agent 当日的完整日换手率。

```python
# Step 2: 按 tom_level 分组
by_tom[tom_level] = [daily_max[(aid, day)] for 所有 (aid,day) with 该 tom_level]
```

每个 ToM 层级得到一个（Agent × 交易日）粒度的样本数组。

### 4.2 每层级的统计

对每个 ToM 层级的样本数组：

- **均值**：$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$
- **95% Bootstrap 置信区间**（重采样 500 次）：
  1. 从原样本中有放回抽样得到同样大小的 bootstrap 样本
  2. 计算该样本的均值
  3. 重复 500 次得到均值分布
  4. 取 2.5% 与 97.5% 分位数为 CI 区间

```python
def bootstrap_ci(vals, B=500):
    rng = np.random.default_rng(42)
    arr = np.asarray(vals)
    means = [arr[rng.integers(0, len(arr), len(arr))].mean() for _ in range(B)]
    return np.quantile(means, 0.025), np.quantile(means, 0.975)
```

### 4.3 采样口径说明

**当前口径**：仅统计"有成交的 (agent, day)"。若某 Agent 某日没有任何成交，该天**不进入样本**。

这意味着：
- 测量的是**"交易活跃日"的平均换手率**，而非"所有交易日的平均换手率（含零交易日）"
- 口径上更接近**条件期望** $E[\text{turnover} \mid \text{trade}=1]$
- 若要转成无条件期望，需额外估算零交易日比例（目前未做）

## 6. 解读注意

1. **单位与量纲**：换手率是比例，不是百分比；`0.10 = 10%` 日换手
2. **不是总换手率**：这是"平均每个活跃 agent 每个活跃日"的换手率，不能直接乘以天数得到累计换手
3. **资产基数**：分母 `total_asset` 是**成交时刻的总资产**，不是日初也不是日末
4. **不同实验可比性**：初始资金分布（幂律 / 等额）与 ToM 配比会影响绝对值；比较时建议关注**同实验内的 ToM 相对差**
5. **零交易日未计入**：若某 ToM 层级整体交易频率低（例如 ToM0 散户），其样本数会少，且可能高估其"活跃日"换手率

## 7. 验证式

- 总样本数 ≈ $\sum_{实验} \sum_{\text{agent}} \text{该agent活跃天数}$
- 典型 ToM2：日换手 10%-16% → 论文中的 KOL / 机构高活跃者画像
- 典型 ToM0：日换手 4%-7% → 散户低频画像
